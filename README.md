# contest-verify

공모전 제출물의 숫자·로직 검증용 저장소

| 폴더 | 대상 | 내용 |
|---|---|---|
| `afpk/` | AFPK 영 플래너 챌린지 2026 | 재무진단·청년미래적금·몬테카를로 달성확률 계산기, 단위테스트, 민감도 분석 |
| `welfare/` | 사회보장 데이터 AI 혁신 아이디어 경진대회 | Rules as Code 판정 엔진(3값 논리) + 적응형 질문 PoC, 페르소나 1,000명 평가 |

## 실행
```bash
pip install numpy pytest
python -m pytest -q          # 11 passed
python -m afpk.fp_simulator  # 시나리오별 만기액·달성확률
python -m afpk.sensitivity   # μ×σ 민감도
python -m welfare.evaluate   # 적응형 vs 전체 질문 비교
```

## 주요 결과 (2026-11-10)
- 적금 이자 닫힌 해 = 월별 루프 독립 구현 (단위테스트 일치). '원금×연이율' 방식은 12개월 기준 1.85배 과대평가
- 결혼자금 4,000만원 달성확률: 기본 가정 91.4%, 하락장(μ=-5%, σ=30%) 57.5%, 우대형 기여금 시 약 100%
- 복지 PoC: 평균 질문 5.00 → 3.65 (27.1% 감소), 판정 일치 100%(결정적 엔진이라 설계상 보장)

## 가정·한계
- 금리·주식 수익률·변동성은 가정값. 청년미래적금 기여금 비율, 연금저축 공제율은 공식 자료로 재확인 필요
- 복지 규칙은 소득 기준만 단순화(재산 환산, 부양의무자 세부 기준 생략). 2026 기준중위소득은 2차 자료 기준
